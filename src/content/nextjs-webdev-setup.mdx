<h2 className="mb-4">🚀 Full Next.js Web App Setup with Development Environment</h2>

This guide will walk you through setting up a complete **Next.js** project from scratch with a modern development environment. We'll use **PNPM**, **TypeScript**, **Tailwind CSS**, **ESLint**, **Prettier**, and more.

---

### 🧰 Step 1: Install Prerequisites

Before starting, ensure the following tools are installed:

### ✅ Required Tools

| Tool         | Purpose                           | Installation Link                          |
|--------------|-----------------------------------|---------------------------------------------|
| **Node.js**  | JavaScript runtime                | [nodejs.org](https://nodejs.org)            |
| **PNPM**     | Fast and efficient package manager| `npm install -g pnpm`                       |
| **Git**      | Version control                   | [git-scm.com](https://git-scm.com)          |
| **VS Code**  | Recommended code editor           | [code.visualstudio.com](https://code.visualstudio.com) |

---

### 🏗️ Step 2: Create a New Next.js App

Run the following commands in your terminal:

```bash
# Create a new Next.js project with TypeScript using pnpm
pnpm create next-app my-app -- --typescript

# Navigate into the project directory
cd my-app
```

> ✅ **Note**: `--typescript` scaffolds the project with TypeScript configuration.

---

### 🚀 Step 3: Run the Development Server

Start the local development server:

```bash
pnpm dev
```

Now open [http://localhost:3000](http://localhost:3000) to view your app.

---

### 🗂️ Step 4: Project Structure Overview

A typical project structure looks like this:

```
my-app/
├── pages/             # App routes (e.g., index.tsx, about.tsx)
├── public/            # Static assets like images
├── styles/            # CSS or Tailwind files
├── components/        # Reusable UI components
├── lib/               # Utility functions or API wrappers
├── hooks/             # Custom React hooks
├── types/             # TypeScript interfaces and types
├── .env.local         # Environment variables
├── next.config.js     # Next.js config
├── tsconfig.json      # TypeScript config
```

---

### 🔐 Step 5: Environment Variables

Create a `.env.local` file for local secrets:

```env
NEXT_PUBLIC_API_URL=https://api.example.com
SECRET_API_KEY=super-secret-key
```

Access in your app code:

```tsx
const apiUrl = process.env.NEXT_PUBLIC_API_URL;
```

> ⚠️ **Note**: Only variables prefixed with `NEXT_PUBLIC_` are exposed to the browser.

---

### 🎨 Step 6: Add Tailwind CSS

Install Tailwind CSS:

```bash
pnpm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

Update `tailwind.config.js`:

```js
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    './pages/**/*.{js,ts,jsx,tsx}',
    './components/**/*.{js,ts,jsx,tsx}',
  ],
  theme: {
    extend: {},
  },
  plugins: [],
};
```

Modify `./styles/globals.css`:

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

### 🧹 Step 7: Setup ESLint & Prettier

### Install dependencies:

```bash
pnpm add -D eslint prettier eslint-config-prettier eslint-plugin-react eslint-plugin-react-hooks eslint-plugin-jsx-a11y @typescript-eslint/eslint-plugin @typescript-eslint/parser
```

### Create `.eslintrc.json`:

```json
{
  "extends": [
    "next/core-web-vitals",
    "plugin:@typescript-eslint/recommended",
    "plugin:react/recommended",
    "plugin:jsx-a11y/recommended",
    "prettier"
  ],
  "plugins": ["@typescript-eslint"],
  "rules": {
    "react/react-in-jsx-scope": "off"
  }
}
```

### Create `.prettierrc`:

```json
{
  "semi": true,
  "singleQuote": true,
  "trailingComma": "all"
}
```
